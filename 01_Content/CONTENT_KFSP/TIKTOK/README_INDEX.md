## 🎯 QUY CHUẨN 1 BẢN KỊCH BẢN TIKTOK CHUẨN KFSP
Mỗi file kịch bản trong kho bắt buộc có 4 phần:
1. **Thông tin tổng quan:** Mã video, Framework (BAB / PAS / Hook-Value-CTA), thời lượng.
2. **Text Voice sạch (Clean Script):** Để bạn copy dán thẳng vào tool tạo Voice TTS trong 1 giây (không dính nhãn s1, s2, bullet, emoji).
3. **Phân cảnh Storyboard chi tiết:** Từng câu kèm hình ảnh visual anchor, animation và hiệu ứng âm thanh (SFX).
4. **Caption & Hashtag đăng bài:** Tiêu đề hook, mô tả và bộ hashtag chính thức của KFSP.
