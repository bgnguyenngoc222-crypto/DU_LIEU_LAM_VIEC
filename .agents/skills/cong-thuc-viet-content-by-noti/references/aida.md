# AIDA (Attention → Interest → Desire → Action)

Dẫn dắt qua 4 giai đoạn cảm xúc tăng dần.

## Cách viết từng phần

- **Attention**: Phá vỡ pattern lướt feed. Dùng số liệu gây sốc, câu hỏi đau, hoặc mâu thuẫn nhận thức. Áp dụng NLP: Open Loop hoặc Presupposition ngay câu đầu.
- **Interest**: Giới thiệu SP với thông tin hấp dẫn + dùng Sensory Language để KH "thấy, nghe, cảm" được SP.
- **Desire**: Vẽ viễn cảnh Future Pacing — mô tả cụ thể cuộc sống sau khi dùng SP bằng ngôn ngữ giác quan. Dùng Embedded Command: "Hãy tưởng tượng bạn đang..."
- **Action**: CTA rõ ràng + Scarcity/Loss Aversion. Dùng kỹ thuật Double Bind: đưa 2 lựa chọn, cả 2 đều dẫn đến mua.

## Tâm lý khuyến nghị

Curiosity Gap (A), Authority (I), Future Pacing + Endowment (D), Scarcity + Loss Aversion (A)

## NLP khuyến nghị

Open Loop / Presupposition (câu đầu), Sensory Language (Interest), Embedded Command (Desire), Double Bind (Action)
