# FAB (Features → Advantages → Benefits)

Biến thông số kỹ thuật khô khan thành lợi ích cảm xúc.

## Cách viết từng phần

- **Features**: Liệt kê tính năng nổi bật (tối đa 3). Dùng Power Words kỹ thuật tạo cảm giác premium.
- **Advantages**: So sánh cụ thể với đối thủ/SP thường. Dùng Contrast Principle + Framing: "Gấp X lần so với..."
- **Benefits**: Chuyển thành ngôn ngữ cảm xúc. Dùng Endowment Effect: "Tưởng tượng bạn đang sở hữu..." + Sensory Language: mô tả cảm giác khi sử dụng (mát, êm, nhẹ, sạch...).

## Tâm lý khuyến nghị

Framing Effect (F→B), Contrast Principle (A), Endowment Effect + Sensory Language (B)

## NLP khuyến nghị

Power Words (Features), Contrast Framing (Advantages), Sensory Language + Embedded Command (Benefits)
