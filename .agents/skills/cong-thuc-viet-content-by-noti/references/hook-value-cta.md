# Hook – Value – CTA

Công thức vàng cho content ngắn (Reels, TikTok, caption Facebook).

## Cách viết từng phần

- **Hook**: 1 câu phá vỡ pattern. Kỹ thuật: Open Loop ("Tôi sẽ tiết lộ..."), Presupposition ("Khi bạn biết điều này..."), Pattern Interrupt (số sốc, mâu thuẫn). Câu hook quyết định 80% hiệu quả.
- **Value**: Cho 1-3 insight/tip hữu ích THẬT SỰ — Reciprocity: KH cảm thấy "được cho" trước khi bị "bán". Dùng Specificity: tip cụ thể > tip chung chung.
- **CTA**: Micro-commitment → macro-action. Dùng Commitment Trigger: "Comment [KEYWORD]" (comment = đồng ý nhỏ → inbox = bước tiếp → mua = chốt).

## Tâm lý khuyến nghị

Curiosity Gap + Pattern Interrupt (Hook), Reciprocity (Value), Commitment Escalation (CTA)

## NLP khuyến nghị

Open Loop / Presupposition (Hook), Specificity Bias (Value), Embedded Command (CTA)
