# SLAP (Stop → Look → Act → Purchase)

Dùng sự bất ngờ/gây sốc để phá vỡ thói quen lướt feed.

## Cách viết từng phần

- **Stop & Look**: Câu mở GÂY SỐC / MÂU THUẪN. Dùng Pattern Interrupt + Open Loop. Ví dụ kỹ thuật: "Đừng mua [SP này]... cho đến khi bạn đọc hết bài này."
- **Act**: Khuyến khích tương tác. Dùng Zeigarnik Effect: để "dở dang" để KH phải xem tiếp.
- **Purchase**: CTA mạnh + FOMO. Dùng Decoy Effect nếu có nhiều gói giá.

## Tâm lý khuyến nghị

Pattern Interrupt + Von Restorff (S), Curiosity Gap + Zeigarnik (L), Urgency + FOMO (P)

## NLP khuyến nghị

Open Loop (Stop), Power Words gây sốc (Look), Double Bind / Scarcity language (Purchase)
