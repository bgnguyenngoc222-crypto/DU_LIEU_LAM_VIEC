# Maps Elements

Danh sách các element bản đồ:

- **A-to-B Map Flyover**: Hiệu ứng bay qua bản đồ từ điểm A đến điểm B, hỗ trợ chỉnh sửa tọa độ, nhãn địa điểm và camera theo dõi tuyến đường.
- **Watercolor Map**: Hành trình trên bản đồ màu nước giữa 2 địa điểm, với các nhãn động, điểm đánh dấu (marker) và tuyến đường vẽ tay.
