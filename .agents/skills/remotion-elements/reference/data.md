# Data Elements

Danh sách các element biểu đồ và dữ liệu:

- **Horizontal Bar Chart**: Biểu đồ cột ngang in đậm với 3 điểm dữ liệu được gắn nhãn trực tiếp.
- **Line Chart**: Biểu đồ đường dạng động với xu hướng được gắn nhãn trực tiếp.
- **Number Counter**: Bộ đếm số dạng động đơn giản, chạy mượt mà từ giá trị bắt đầu đến giá trị kết thúc.
- **Pie Chart**: Biểu đồ tròn dạng động in đậm với 4 điểm dữ liệu được gắn nhãn.
- **Vertical Bar Chart**: Biểu đồ cột dọc in đậm với 3 điểm dữ liệu được gắn nhãn.
