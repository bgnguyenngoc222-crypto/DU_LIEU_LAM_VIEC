# Backgrounds Elements

Danh sách các hình nền (backgrounds) có sẵn:

- **Notebook Paper**: Nền giấy trắng với các đường kẻ sọc xanh nhạt.
- **Paper Texture**: Nền chất liệu giấy trắng với seed nhiễu thay đổi chậm (posterized).
- **Rotating Starburst**: Nền màu đồng nhất với hiệu ứng tia sáng (starburst) xoay chậm.
- **Liquid Contours**: Nền hai màu chảy mượt mà tạo từ các dải viền chất lỏng chuyển động.
