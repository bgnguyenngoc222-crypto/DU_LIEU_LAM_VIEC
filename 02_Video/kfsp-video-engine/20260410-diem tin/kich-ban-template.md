# KỊCH BẢN VIDEO ĐIỂM TIN KFSP — Template TDM

> **Cấu trúc:** Top-Down Market (Thị trường → Ngành → Cổ phiếu → CTA)
> **Thời lượng:** 80-100 giây | **Format:** 9:16 (Shorts/TikTok/Reels)

---

## MỤC 1: THỊ TRƯỜNG & CHỈ SỐ (~20s)

### 1A. Chỉ số + Thanh khoản (~12s)

```
[OPENING — 3s]
Điểm tin thị trường ngày {DD/MM/YYYY}

[CHỈ SỐ — 5s]
VN-Index {tăng/giảm} {X} điểm, tương ứng {X}%
Đóng cửa tại mốc {X} điểm
HNX {tăng/giảm} {X}%, VN30 {tăng/giảm} {X}%

[THANH KHOẢN — 4s]
Thanh khoản toàn thị trường đạt {X} tỷ đồng
{Tăng/Giảm} {X}% so với phiên trước
```

**Hình ảnh:** Screenshot app KFSP → tab "Thị Trường" (VNI/HNX/VN30)

### 1B. Độ rộng + Tỉ trọng (~8s)

```
[ĐỘ RỘNG — 4s]
Thị trường nghiêng về {phe mua/bán}
Với {X} mã tăng so với {X} mã giảm

[TỈ TRỌNG — 4s]
{Nhận định ngắn: ví dụ "Phe mua chiếm ưu thế nhẹ" 
hoặc "Áp lực bán vẫn lớn hơn"}
```

**Hình ảnh:** Screenshot app KFSP → chart "Số lượng mã tăng giảm theo thời gian"

## MỤC 2: NGÀNH → CỔ PHIẾU NỔI BẬT (~30s)

> **Lưu ý:** Mục này THAY ĐỔI MỖI NGÀY. Số ngành = 2-4 ngành nổi bật nhất.
> Dữ liệu từ: **Nỗ lực & Kết quả Wyckoff** (nhìn ngành) + **Bản đồ nhiệt** (nhìn cổ phiếu)

### 2A. Tổng quan ngành (~5s)

```
[CHUYỂN CẢNH — giới thiệu Wyckoff]
Soi chiếu dưới lăng kính Wyckoff trên KFSP
{Nhóm A} và {Nhóm B} là điểm đến của dòng tiền hôm nay
```

**Hình ảnh:** Screenshot app KFSP → "Nỗ lực kết quả" tab Ngành

### 2B. Ngành nổi bật #1 (~8s)

```
[NGÀNH 1 — tên + số liệu]
Nhóm {tên ngành} {tăng/giảm} {X}%
Với thanh khoản {tăng/giảm} {X}% so với phiên trước
{Lý do ngắn: ví dụ "Dòng tiền đổ mạnh vào nhóm này"}

[CỔ PHIẾU NỔI BẬT NGÀNH 1]
Nổi bật là {mã 1} {tăng X%} và {mã 2} {tăng X%}
```

**Hình ảnh:** Screenshot app KFSP → Bản đồ nhiệt ngành đó

### 2C. Ngành nổi bật #2 (~8s)

```
[NGÀNH 2 — tương tự cấu trúc 2B]
Nhóm {tên ngành} {tăng/giảm} {X}%
...
Nổi bật là {mã 1} và {mã 2}
```

**Hình ảnh:** Screenshot app KFSP → Bản đồ nhiệt ngành đó

### 2D. Ngành đáng chú ý / áp lực (~9s)

```
[NGÀNH KHÁC — có thể là ngành giảm hoặc đáng quan sát]
{Nhóm X} cũng đóng vai trò {mô tả vai trò}
{Số liệu ngắn}

[HOẶC: Ngành chịu áp lực]
Áp lực bán đang gây sức ép tại nhóm {tên ngành}
{Mã cụ thể chịu áp lực}
Thanh khoản {tăng/giảm} nhưng {giá giảm/sideway}
```

**Hình ảnh:** Screenshot app KFSP → Bản đồ nhiệt / Nỗ lực kết quả

## MỤC 3: CHUYỂN ĐỘNG NỔI BẬT — RS/RRG (~20s)

> **Mục đích:** Showcase tính năng KFSP (RS, RRG) + cung cấp insight sâu hơn
> Dữ liệu từ: **Toàn cảnh thị trường** → tab RRG / RS trên KFSP

### 3A. Nhận định dòng tiền (~6s)

```
[TỔNG KẾT]
Dòng tiền đang có sự {phân hóa/tập trung/dịch chuyển} rõ rệt
Nhà đầu tư cần quan sát kỹ dòng tiền đang chảy đến đâu
```

### 3B. Giới thiệu RS/RRG (~8s)

```
[TÍNH NĂNG KFSP]
Hãy sử dụng biểu đồ RRG trên KFSP
Nhằm khoanh vùng rõ nét nhóm ngành đang dẫn dắt hay suy yếu

[RS DATA]
{Ngành A} đang ở vùng {Leading/Improving/Weakening/Lagging}
{Ngành B} RS {tăng/giảm} mạnh gần đây → {nhận định}
```

**Hình ảnh:** Screenshot app KFSP → RRG quadrant + RS lines

### 3C. Cổ phiếu đáng quan sát (~6s)

```
[TỪ RS/RRG]
Đáng chú ý {mã X} với RS {tăng/giảm}
{Mã Y} đang {chuyển từ Improving sang Leading / ...}
Từ đó tối ưu hóa danh mục đầu tư của bạn
```

## MỤC 4: BỘ LỌC CỔ PHIẾU + CTA (~10s)

> **Mục đích:** CTA tải app KFSP thông qua showcase tính năng Bộ lọc

### 4A. Giới thiệu Bộ lọc (~5s)

```
[BỘ LỌC]
Và để không bỏ lỡ cơ hội
Hãy sử dụng Bộ lọc cổ phiếu trên KFSP
Lọc nhanh theo {RS, CANSLIM, thanh khoản đột biến, ...}
```

**Hình ảnh:** Screenshot app KFSP → Bộ lọc cổ phiếu

### 4B. CTA + Kết (~5s)

```
[CTA]
Tải ngay KFSP
Để cập nhật diễn biến thị trường và dòng tiền nhanh chóng

[KẾT]
Xin chào và hẹn gặp lại
```
