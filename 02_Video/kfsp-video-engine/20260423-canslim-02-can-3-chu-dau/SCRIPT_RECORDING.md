## Quy trình thu

1. Mở `audio/sXX.mp3` trong trình player → nghe pacing Vbee Thanh Long làm reference
2. Thu đè vào file cùng tên `audio/sXX.mp3` (giữ tên, replace file)
3. Re-run whisper:
   ```bash
   python3 scripts/gen_audio_per_sentence.py --only sXX --skip-tts
   ```
4. Copy sang Remotion: `cp audio/sXX.mp3 remotion-canslim/public/audio/sXX.mp3`
5. Re-run sentences.data.json regen + render lại Full

Hoặc thu hết một lần rồi chạy whisper batch + re-render.
