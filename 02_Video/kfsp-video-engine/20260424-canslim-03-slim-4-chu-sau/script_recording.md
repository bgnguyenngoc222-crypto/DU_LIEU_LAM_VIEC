## Workflow sau khi thu

```bash
# 1. Đặt file thu vào audio/ (đè lên Vbee placeholder, giữ tên sNN.mp3)
cp my_recording_s01.mp3 audio/s01.mp3
cp my_recording_s02.mp3 audio/s02.mp3
# ... etc cho từng câu (hoặc thu 1 file dài rồi cắt)

# 2. Re-run whisper để lấy timing thật
python3 scripts/whisper_per_sentence.py s01 s02 s03 ...

# 3. Sync audio + sentences.json sang Remotion
cp audio/*.mp3 remotion-canslim03/public/audio/
cp sentences.json remotion-canslim03/src/

# 4. Re-render (tất cả 26 câu)
cd remotion-canslim03
for s in s01 s02 ... s27; do
  npx remotion render "Sentence-$s" --output=../clips/$s.mp4
done

# 5. Stitch + 1.5x demo
cd ..
python3 scripts/stitch_final.py
ffmpeg -i final.mp4 -filter_complex "[0:v]setpts=PTS/1.5[v];[0:a]atempo=1.5[a]" -map "[v]" -map "[a]" final_1.5x.mp4
```
